# Sniper Orders Pro

نفس محرّك Sayad Orders (نفس منطق القبول والفلاتر بدون أي تغيير)، مع نظام اشتراك بأكواد:
- كل كود مربوط بجهاز واحد فقط (ما يتكرر استخدامه).
- عدّاد تنازلي بدائرة صغيرة فوق الشاشة.
- الصيد يتوقف تلقائياً لما تخلص مدة الكود.
- لوحة إدارة (admin/admin.html) تولّد لك أكواد بالجملة وتوريك اسم كل جهاز والوقت المتبقي وعدد الطلبات المقبولة جنب كل كود، وفيها تقدر تلغي أي اشتراك فوراً.

## تحديث: صار التثبيت الجديد "تحديث" حقيقي فوق القديم
من هالنسخة وطالع، كل بناء (build) بيتوقّع بنفس المفتاح الثابت (`app/sniper-release.keystore`)،
فلما توزّع نسخة جديدة على ناس عندهم نسخة قديمة، بيثبّتوها كـ"تحديث" مباشرة بدون ما يحتاجوا
يمسحوا التطبيق القديم أول — بشرط واحد بس: **رفع رقم الإصدار** `versionCode` فوق كل مرة بتسوي
بناء جديد تنشره (موجود بملف `app/build.gradle.kts`)، وإلا أندرويد ممكن يرفض التثبيت باعتباره نفس
الإصدار أو أقدم.

**ملاحظة مهمة لمرة وحدة:** أي شخص عنده نسخة من قبل هالتحديث (موقّعة بمفتاح عشوائي كان يتغيّر
كل مرة من GitHub Actions)، لازم يمسح التطبيق القديم ويثبّت هالنسخة مرة وحدة بس. بعد هالمرة،
كل التحديثات الجاية بتنزل فوق بعضها عادي بدون مسح.

**لا تحذف ملف `sniper-release.keystore` ولا تغيّر كلمة السر بـ `build.gradle.kts` أبداً** — لو
ضاع أو تغيّر، بترجع لنفس المشكلة (ناس كتير مثبتين النسخة القديمة، والتحديث الجاي ما رح يتثبّت
فوقها).

## تحديث: نشر قواعد Firestore الجديدة
إذا كان عندك مشروع شغّال من قبل، لازم تنسخ محتوى `firestore.rules` الجديد وتلصقه بتبويب Rules وتضغط Publish مرة ثانية، عشان يسمح بتسجيل الطلبات المقبولة.

## خطوات لازم تسويها مرة وحدة بس (قبل أول بناء)

### 1) تفعيل Firestore
إذا لسا ما سويتها: Firebase Console > مشروعك > Firestore Database > Create database > Database ID = `default` > Create.

### 2) نشر قواعد الأمان (Rules)
افتح Firestore Database > تبويب **Rules**، امسح اللي موجود، والصق محتوى ملف `firestore.rules` من هذا المشروع، وادفع **Publish**.

### 3) تفعيل تسجيل الدخول (Authentication) — لحسابك إنت بس
1. من القائمة الجانبية: **Build > Authentication > Get started**.
2. تبويب **Sign-in method**، فعّل **Email/Password**.
3. تبويب **Users > Add user**، أدخل إيميلك وكلمة مرور (هاد حسابك الخاص لفتح لوحة الإدارة، مش له علاقة بالتطبيق).

### 4) افتح لوحة الإدارة
افتح ملف `admin/admin.html` من جهازك (دبل كليك، بيفتح بالمتصفح مباشرة بدون أي استضافة)، سجّل دخول بنفس الإيميل وكلمة المرور، وولّد أول دفعة أكواد.

## البناء على GitHub
نفس خطوات Sayad Orders بالضبط:
1. ارفع كل الملفات (ما عدا مجلد admin إذا بدك، هو مش جزء من التطبيق) لمستودعك.
2. تبويب Actions > Build APK، استنى يخلص.
3. نزّل **SniperOrdersPro-APK** من Artifacts.

## ملاحظة أمان
لوحة الإدارة (admin.html) فيها مفاتيح المشروع العامة (نفس الموجودة أصلاً بـ google-services.json، مش سرّية بطبيعتها)، لكن أي عملية إنشاء/تعديل/حذف محمية بتسجيل الدخول (خطوة 3). لا تشارك إيميل وكلمة مرور حسابك مع حدا.
